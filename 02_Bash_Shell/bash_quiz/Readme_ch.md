# 测验说明
请务必严格遵循每组说明。每次保存答案后，请仔细检查。
创建答案文件后，您可以跳过无法回答的问题。
注意：您可以在浏览器中打开此文件，但**所有步骤，包括创建答案文件，都必须在终端中完成，而不是在 GUI（图形用户界面）中完成。**如果您忘记了如何使用命令，可以使用笔记或互联网。别忘了，还有手册页。

## 创建答案文件并初始化测验
在您的“桌面”上创建一个名为“your_name_quiz.txt”的文件，将“your_name”替换为您的真实姓名。文件命名时请使用下划线，不要使用空格。
在“bash_quiz”目录中，您将找到一个名为“init_quiz.sh”的文件。执行此脚本。

## 1) 添加一行
在你的答案文件中添加一行“1)”
在你当前所在的目录中找到名为“fingerprint.txt”的文件
将其**所有内容**添加到你的答案文件中。

## 2) 查找特定行
在你的答案文件中添加一行“2)”
在你当前目录的下一个目录中，你会找到一个名为“Blasting_dictionary-master”的目录。
进入此目录并找到以“3389”开头的文件。
将以“idcj”开头的**文本行**添加到你的答案文件中。

## 3) 查找文件
在你的答案文件中添加一行“3)”
在本测验的其中一个目录中有一个名为“keyboard_top100.txt”的文件。
找到此文件并将其**文件路径**添加到你的答案文件中。

## 4) 对文件进行排序
在你的答案文件中添加一行“4)”
在“Fuzzing-Dicts-master”目录中的某个位置有一个名为“forward.txt”的文件
对该文件的内容进行排序，并将其附加到你的答案文件中。

## 5) 在多个文件中搜索字符串
在你的答案文件中添加一行“5)”
在其中一个测验目录中有一个包含密码“PasswordShmashword775”的文件
找到包含此密码的文件，并将文件名（而不是密码）附加到你的答案文件中。

## 6) 查找隐藏文件
在你的答案文件中添加一行“6)”
在“Fuzzing-Dicts-master”目录中有一个隐藏文件。将此文件的内容附加到你的答案文件中。

## 7) 不区分大小写的搜索
在你的答案文件中添加一行“7)”
“Fuzzing-Dicts-master”中的一个文件包含一行包含单词“therhinoserver”的内容。但是，部分字母是大写，部分字母是小写。请将此行添加到你的答案文件中。

## 8) 搜索包含空格的文件名
在你的答案文件中添加一行“8)”
在“Fuzzing-Dicts-master”目录中有一个名为“MySQL-Password (3050) .txt”的文件。在此文件中搜索包含“k1ng1”的行，并将此行添加到你的答案文件中。

## 9) 运行评分脚本
如果你还没有切换到“bash_quiz”目录，请切换回“bash_quiz”目录。然后执行名为“grade_quiz.sh”的脚本。完成后给我打电话。
